# 捡球小车练习场

一个面向 Python 初学者的 ESP32 捡球小车模拟平台第一版。

## 在 VS Code 中运行

1. 用 VS Code 打开本目录。
2. 使用 Live Server，或在终端运行 `python -m http.server 8000`。
3. 浏览器打开 `http://localhost:8000`。

页面使用浏览器内的教学模拟器执行小车指令，不依赖后端服务或外部 Python 环境。

## 当前功能

- 三个循序渐进的 Python 任务
- 小车前进、后退、转向、停止和距离传感器模拟
- 普通运行、单步提示、示例恢复
- 本地保存学习进度
- 导出当前练习为 `.py` 文件，方便在 VS Code 中继续查看
- 每关两次帮助提示，之后提示通过微信联系陪练
